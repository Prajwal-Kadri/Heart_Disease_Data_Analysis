# Heart Disease Data Analysis

An exploratory data-analysis and machine-learning notebook using a heart-disease dataset with 303 records and 13 clinical features.

## Contents

- `IT204Proj.ipynb` — data loading, exploratory analysis, visualisation, and model experiments
- `heart.csv` — dataset used by the notebook

## Run locally

```bash
python -m pip install jupyter numpy pandas seaborn matplotlib scikit-learn
jupyter notebook IT204Proj.ipynb
```

Run the notebook cells in order. The analysis expects `heart.csv` in the repository root.

## Scope

This is an academic exploratory project. It is not a medical diagnostic tool and should not be used for clinical decisions.
